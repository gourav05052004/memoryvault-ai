# MemoryVault AI Backend

## Environment variables

Create/update `backend/.env` with:

```
MONGO_URI="your_mongodb_uri"
GEMINI_API_KEY="your_gemini_api_key"
GEMINI_CHAT_MODEL="gemini-3-flash-preview"
EMBEDDING_MODEL="gemini-embedding-001"
TESSERACT_CMD="C:\\Program Files\\Tesseract-OCR\\tesseract.exe"
JWT_SECRET_KEY="change-this-in-production"
JWT_ALGORITHM="HS256"
JWT_EXPIRE_MINUTES="60"
```

`GEMINI_API_KEY` is required for embeddings, summary/tag generation, ask responses, and query parsing.

## Run

From `backend/`:

```
pip install "python-jose[cryptography]" "passlib[bcrypt]" "bcrypt==4.0.1"
python -m uvicorn app.main:app --reload --port 8001
```

## Reindex existing memories into Chroma (one-time)

If you already have memories in MongoDB and want to rebuild vector search without re-uploading files:

```
python reindex_chroma_from_mongo.py
```

- Default mode resets Chroma and rebuilds all vectors from Mongo.
- To upsert without resetting the collection:

```
python reindex_chroma_from_mongo.py --no-reset
```
## Deployment to Render

### Prerequisites
- MongoDB Atlas account (for cloud MongoDB)
- Supabase account (for file storage)
- Gemini API key from Google AI Studio
- GitHub repository connected to Render

### Quick Deploy

1. **Push your code to GitHub** (including `Dockerfile` and `render.yaml`)

2. **Connect to Render:**
   - Go to [Render Dashboard](https://dashboard.render.com/)
   - Click "New" → "Blueprint"
   - Connect your repository
   - Render will auto-detect `render.yaml`

3. **Set REQUIRED environment variables in Render dashboard:**
   
   | Variable | Where to get it | Example |
   |----------|----------------|---------|
   | `GEMINI_API_KEY` | [Google AI Studio](https://aistudio.google.com/apikey) | `AIzaSy...` |
   | `MONGO_URI` | [MongoDB Atlas](https://cloud.mongodb.com/) → Connect | `mongodb+srv://user:pass@cluster.mongodb.net/memoryvault` |
   | `SUPABASE_URL` | Supabase Dashboard → Settings → API | `https://xxxxx.supabase.co` |
   | `SUPABASE_KEY` | Supabase Dashboard → Settings → API → anon/public key | `eyJhbGc...` |
   | `FRONTEND_URLS` | Your deployed frontend URL | `https://yourapp.vercel.app` (or comma-separated for multiple) |
   | `TESSERACT_PATH` | ✅ Auto-set in Dockerfile | `/usr/bin/tesseract` |
   
   **Note:** `JWT_SECRET_KEY` is auto-generated by Render (see render.yaml)

4. **Deploy** - Render will build the Docker image and deploy

### Manual Deploy (without render.yaml)

1. Create a new Web Service on Render
2. Select "Docker" as environment
3. Set Dockerfile path: `./backend/Dockerfile`
4. Add all environment variables from the table above, plus:
   - `TESSERACT_CMD` = `tesseract`
   - `JWT_SECRET_KEY` = (generate a secure random string)
   - `LOG_LEVEL` = `INFO` (optional)
5. Deploy

### Important Notes

- **Lighter & Faster:** No transformers/torch means faster builds and lower memory usage
- **Scaling:** Can use Render's starter ($7/mo) or free tier (previously needed $25+/mo)
- **Storage:** ChromaDB data persists in Render disk storage; consider using external vector DB for production at scale
- **Tesseract:** Included in Dockerfile for image OCR support
- **CORS:** Make sure `FRONTEND_URLS` matches your actual frontend domain
